# Пульт управления Starship / Super Heavy

Симулятор полёта двухступенчатой системы Starship: динамика полёта, модель ЖРД Raptor
с турбонасосными агрегатами, автоматика выведения, возврат ускорителя на стартовый стол,
выход на орбиту, сход с орбиты и посадка корабля.

## Как запустить

**Проще всего** — взять готовый архив во вкладке
[Releases](https://github.com/tikD1337/starship-sim/releases). Ставить ничего не нужно,
Godot и .NET внутри; из требований только видеокарта с Vulkan.

| система | файл | как запускать |
|---|---|---|
| Windows 64-бит | `Starship-win64.zip` | распаковать, запустить `Starship.exe` |
| Linux x86_64 | `Starship-linux-x86_64.zip` | `chmod +x Starship.x86_64 && ./Starship.x86_64` |
| macOS, Intel и Apple Silicon | `Starship-macos-universal.zip` | сперва снять карантин, см. ниже |

Сборка для macOS не заверена у Apple (это платно), поэтому на маках с чипом M первый
запуск кончается сообщением «Starship.app is damaged and can't be opened». Приложение
не повреждено — так macOS встречает всё, что скачано без заверения Apple. Снимается
одной командой. Откройте Терминал, наберите `xattr -dr com.apple.quarantine ` (с пробелом
в конце), перетащите в окно `Starship.app` — путь подставится сам — и нажмите Enter.
Или, если Терминал уже открыт в папке с приложением:

```bash
xattr -dr com.apple.quarantine Starship.app
```

Дальше приложение открывается обычным двойным щелчком.

Если хотите собирать сами, нужны две вещи:

* **Godot 4.7.2 .NET** (сборка mono — та, что умеет C#) — [godotengine.org](https://godotengine.org/download/)
* **.NET SDK 8.0** — [dotnet.microsoft.com](https://dotnet.microsoft.com/download)

```bash
git clone <адрес репозитория>
cd starship
```

На Windows проще всего запустить `game/play.bat` — он подставляет переменные среды,
собирает и запускает. Пути к Godot и .NET внутри прописаны под мою машину, поправьте
две строки в начале файла под свою.

Вручную, на любой системе:

```bash
dotnet build game
godot --path game
```

Первый запуск дольше обычного: Godot импортирует модель и текстуры.

**Проверить физику, не запуская игру:**

```bash
dotnet run --project game/tests/SimTests -c Release                     # 128 проверок: физика, полёты, интерфейс
dotnet run --project game/tests/SimCheck -c Release -- mission orbital  # полёт целиком, сводка чисел
python game/tests/bench/bench.py run --seeds 20 -- --disp              # стенд: 40 полётов с разбросом (нужна сборка SimCheck)
```

Стенды не тянут Godot — это та же физика отдельной сборкой, они идут в консоли и на
Linux с macOS тоже.
На GitHub проверки и стенд идут сами при каждом пуше: 11 наборов по 40 полётов (трансатмосферное — 20),
исходы и цифры посадки против последнего прогона `main` — в сводке прогона и комментарием в PR; новый
провал или заметно худшая медиана посадки делает проверку красной.

### Про модель

Корпуса, рули, закрылки и колокола двигателей берутся из модели
[SpaceX Starship Block 3](https://sketchfab.com/3d-models/spacex-starship-block-3-6f6c6f88a3eb4b4d822fdca66733fbb2)
автора **Clarence365**, лицензия CC BY 4.0. Башня и стол строятся
параметрически. Подробности — в [ATTRIBUTION.md](ATTRIBUTION.md).

Рядом лежит `starship_proc.glb` — полностью самодельная сборка того же аппарата из
примитивов, вчетверо легче. Игра берёт её, если детальной модели рядом нет.

## Что моделируется

**Динамика полёта** — плоская задача в инерциальной СК с центром Земли: тяга, гравитация
(`μ/r²`), вращение атмосферы, стандартная атмосфера USSA-76 до 1000 км, сопротивление с
зависимостью Cx от числа Маха, донное сопротивление при полёте хвостом вперёд, нормальная
сила и момент относительно центра масс. Центр масс смещается по мере выработки топлива,
момент инерции считается по частям — двигательный отсек, верхний узел, обечайка, столб топлива
по текущему уровню, головные баки: полный ускоритель разворачивается легче, пустой — тяжелее.
фокус аэродинамики зависит от угла атаки — поэтому ускоритель устойчив «хвостом вперёд»,
а корабль с носовыми баками — «брюхом к потоку» на α≈60–70°.

**Управление** — распределение потребного момента между качанием сопел (гимбал),
закрылками и двигателями малой тяги. Сопло перекладывается не быстрее 30°/с, у каждого
двигателя своё плечо: отказ двигателя или посадка на одном смещённом от оси двигателе
разворачивают корпус, и автомат парирует это отклонением сопел. Автомат стабилизации ведёт
тангаж по угловой скорости: раскручивает корпус не быстрее, чем тот успеет затормозить
с учётом запаздывания привода, поэтому не перелетает даже при малом запасе момента.
Коэффициенты правятся в панели «Рулевой тракт». Вращение гасит только воздух: демпфирование
тангажа считается из поперечного обтекания корпуса, и в пустоте закрученный корабль
вращается, пока его не остановят двигатели. При горячем разделении тяга корабля действует на
связку, а сама расстыковка сохраняет импульс и вращение — толчков из ниоткуда нет. Проверки
«без автомата» задают сопло, рули и ДМТ напрямую и сверяют полёт с расчётом на бумаге:
ракетное уравнение, момент на инерцию, сохранение вращения, падение в атмосфере.

**Рули и закрылки** — не просто рули, а аэродинамические поверхности со своей силой и приводом.
Решётчатые рули ускорителя дают нормальную силу по местному углу потока (с учётом вращения
корпуса) и сопротивление, отклоняются не дальше ±25° и не быстрее 20°/с. Поэтому падающая
ступень с раскрытыми рулями сама встаёт по потоку, как оперённая стрела, а со сложенными —
кувыркается. Закрылки корабля складываются к подветренной стороне до 85° со скоростью 26°/с;
их сила — по Ньютону от угла атаки и открытой потоку доли. Балансировку падения брюхом задают
они: передние выпущены, задние сложены — корабль ложится поперёк потока, наоборот — клюёт носом.
Автомат подбирает отклонение по модели поверхностей и упирается в их настоящие пределы. В сцене
рули и закрылки двигаются за фактическим углом привода; боковые решётчатые рули работают
навстречу друг другу, закрылки складываются вокруг петли, наклонённой вдоль носового конуса.

**Двигатели** — каждый из 33 (ускоритель) и 6 (корабль) Raptor считается отдельно:
вал с турбиной и governor'ом, насосы горючего и окислителя (напор ∝ n², расход, КПД,
мощность 30–35 МВт на насос), кавитация по запасу NPSH, нагрев подшипников, вибрация,
износ крыльчаток. Давление в камере получается из напора насосов, тяга ступени —
сумма по двигателям. Отказ подшипников или крыльчатки гасит двигатель.

**Баки и наддув** — подушка наддува растёт по мере выработки: газ подаётся автогенно
(отбор от работающих двигателей) и из баллонов высокого давления. Если подача не успевает
за расходом, давление на входе насосов падает, запас NPSH исчезает и начинается кавитация —
тяга просаживается. У корабля есть головные баки (42 т), из которых идёт переворот и
посадочная жига, поэтому остаток в основных баках на посадку уже не влияет.

**Топливо в баках** ведёт себя как жидкость. Под тягой или торможением оно лежит на днище,
а в невесомости за доли секунды всплывает. Насос тогда забирает газ вместо жидкости, и
двигатель, запущенный на всплывшем топливе, выключается аварийно. Поэтому перед запуском на
орбите — довыведением и сходом — корабль две-три минуты мягко толкает себя вперёд двигателями
малой тяги, пока топливо не осядет, как это делали S-IVB и Centaur: чем слабее толчок, тем дольше, но
тем меньше уходит газа. Довыведение и сход поэтому начинаются заранее, с упреждением на осадку. Ускоритель, как настоящий, при
разделении не гасит три центральных двигателя и разворачивается на них. На входе насоса к
давлению наддува прибавляется столб жидкости. В неполных баках жидкость плещется: первый тон
колебаний считается как маятник, масса и частота которого зависят от уровня и перегрузки.
Волна и сдвиг центра масс дают момент на корпус. На спуске остаток кислорода прижимается к
стенке и сдвигает центр масс ускорителя примерно на 0,4 м. Автомат учитывает этот сдвиг по
показаниям акселерометров, а саму волну парирует как помеху.

**Газ двигателей малой тяги** не бесконечный. ДМТ — холодногазовые сопла на газе из подушек основных
баков, как у летавших кораблей и ускорителей: передние на метане, задние и осадка на кислороде. Тяга
звукового сопла пропорциональна давлению в баке за вычетом давления снаружи, поэтому у земли ДМТ слабее,
чем в пустоте, а израсходованный газ роняет давление наддува. Удельный импульс — из свойств газа: кислород
50 с, метан 72 с. Автомат поэтому экономит: в пустоте разворачивается не быстрее 1,5°/с, осаживает топливо
мягко, а балансировку в воздухе держат закрылки и рули, не ДМТ. За полёт корабль тратит около 3,3 т газа,
ускоритель — около тонны; на пульте — строка «Газ на ДМТ».

**Полезная нагрузка** — в носовой части корабля грузовой отсек с партией Starlink V3
(45 аппаратов на орбитальном задании, 13 на высокой орбите). Створка открывается только вне
плотных слоёв атмосферы, аппараты уходят «пез-диспенсером» по одному и дальше летят
самостоятельно по своим орбитам — их видно рядом с кораблём в обзоре. Перед сходом с орбиты
корабль выпускает всю партию сам и возвращается пустым; вручную — `B`, `N`, `M`.

**Возврат на башню** — обе ступени наводятся на ловильные руки Mechazilla (62 м над столом).
Ускоритель, как настоящий Super Heavy, разворачивается на трёх центральных двигателях, не
погашенных при разделении, и зажигает ещё десять: тормозной импульс тринадцатью двигателями
разворачивает его к старту; дальше он молча падает
хвостом вперёд под углом атаки около 17° — столько держат решётчатые рули на пределе отклонения
(у полёта 9 было ~17°). Корпус под углом и сами рули тормозят ступень, поэтому напор на спуске
остаётся ниже предела конструкции. Сопротивление рулей не опубликовано; его коэффициент (0,2 на
площадь рамки) определён по единственному наблюдению — жиге полёта 5 на ~1250 км/ч. Подъёмной силой ускоритель рулит, как корабль на входе: креном
поворачивает её из плоскости полёта или в неё, а крен подбирается по прогнозу точки падения,
в котором учтены и сопротивление, и подъёмная сила. Посадочная жига включается на 1,6–1,9 км
при 1250–1360 км/ч: 13 двигателей гасят скорость за 6–7 с, три центральных доводят ступень до
рук, вся жига занимает 22–26 с (у настоящего 26). Если почти пустой ступени и на минимальном
дросселе трёх двигателей не снизиться, один из них гасится. Если захват отменён — не зажглись двигатели,
мало топлива, ветер у башни сильнее 20 м/с, — ускоритель уходит в море за берегом.

**Спуск корабля с орбиты** сделан так же, как на настоящих спускаемых аппаратах.
Потребный тормозной импульс подбирается прогоном модели спуска (деление пополам по Δv),
отсечка идёт по набранному импульсу и уточняется тем же прогнозом — в неё входят и потери
на разворот, и длительность горения. Перед входом лишнее топливо сливается: с полными баками
центровка уходит к носу, фокус оказывается позади неё, и корпус устойчив уже хвостом вперёд —
на «брюхо» его никакими закрылками не поставить.

Дальностью на входе управляют **угол атаки и крен**. Угол атаки — 62° выше 60 км и 70° ниже, с
общей поправкой; вектор подъёмной силы поворачивается креном вокруг вектора скорости. Крен 0° —
вся подъёмная сила вверх, спуск пологий и дальний; 90° — сила уходит из плоскости полёта; больше
90° — вниз, спуск крутой и короткий. Поправку и крен подбирает прогноз: он пролетает весь спуск до
точки переворота по тем же законам, что и корабль, включая участок ниже 25 км и падение плашмя.
Поэтому поправка ставится сразу, на ~115 км, и дальше почти не меняется. Ниже 25 км поток идёт снизу, та же сила работает как боковая,
и тем же креном корабль гасит снос. Когда спуск становится почти отвесным, корабль падает
плашмя и рулит наклоном корпуса: передние закрылки выпущены, задние сложены, и разностью
между ними автомат держит корпус поперёк потока. В точку переворота, в 200 м до башни, он приходит с точностью в несколько метров, а
сам переворот толкает его вперёд, к рукам. Дальше один двигатель доводит корабль до захвата —
около 18 с от зажигания; в баках остаётся ~33 т, запас на ожидание у рук и уход в море.

**Тепло** — тепловой поток `q = 1.83e-4·√(ρ/R)·V³`, двухузловая модель теплозащиты
(плитка излучает наружу и греет силовой корпус). Плитки в обзоре светятся по своей
температуре — от вишнёвого к белому, перед наветренной стороной стоит ударный слой
с плазменным следом.

**Башня и ловля.** Башня Mechazilla высотой 140 м стоит сбоку от стола, её «палочки» —
по 36 м. На подходе ступени руки раскрыты на 10 м от корпуса, а когда штыри опускаются к
рельсам, каждая рука сходится к корпусу там, где он есть: если ступень пришла левее, левая
почти не двигается, а правая проходит далеко. Потом руки вместе переносят ступень на ось
стола, и подъёмная каретка опускает её на стол. Берут не за середину корпуса, а за штыри у
верхнего днища, которые ложатся на рельсы. Ловят только спокойную ступень: наклон до 6°,
вращение до 3°/с.

**Отказы и разброс.** Starship — машина недоведённая, поэтому пуск на пуск не
приходится. Каждый полёт идёт со своим зерном (оно видно на пульте): сухая масса, заправка,
тяга каждого двигателя, плотность воздуха и ветер с порывами немного другие, и промах, время
посадки и поведение у башни каждый раз свои. `R` — новый полёт, `Shift+R` — тот же заново.
`F7` включает розыгрыш неисправностей: двигатель может не выйти на режим, погаснуть в полёте
или не зажечься на посадку, турбонасос — просесть, наддув — потечь, привод закрылка —
заесть, часть плиток — отвалиться. Наведение правды не знает: положение и скорость читает с
шумом и запаздыванием, ветер оценивает по сносу. Опор у ступеней нет, поэтому исходов два —
руки или море, касание суши означает потерю. Если захват становится рискованным, ступень уходит
в море. Корабль решает это дважды: на 25 км по прогнозу ветра и на 3 км по ветру, который
намерил сам, пока ещё планирует брюхом и может увести глиссаду к воде. Отказ одного-двух
посадочных двигателей корабля — не повод уходить: на конце жиги работает один, и корабль
ловится на оставшихся.

## Задания

| Задание | Что происходит |
|---|---|
| Орбитальное — 200 км | Выведение, ловля ускорителя башней, круговая орбита ~200 км, выпуск 45 Starlink, сход с орбиты, вход, переворот и ловля корабля башней. Обе ступени возвращаются на башню |
| Трансатмосферное | Суборбитальный профиль как у испытательных пусков: корабль входит в атмосферу и приводняется в ~10 700 км от старта |
| Высокая орбита — 500 км | То же, но груз 20 т (13 Starlink) и довыведение на 500 км |

## Управление

Полный список — по `F1` прямо в игре. Ниже основное.

| | |
|---|---|
| `Tab` | следующий экран по кругу: сводка, эфир, пульт |
| `F3` … `F5` | график на пульте: телеметрия, развёртка, коридор входа |
| `F6`, `F7` | следующее задание, отказы вкл/выкл |
| `F8` | таблица рекордов по заданиям и нештатным ситуациям |
| `F9`, `F10` | записать прогон, повторить записанный |
| `F11` | разбор полёта: вехи, напор, нагрев, судьба ступеней |
| `пробел` | пауза |
| `[`, `]` | скорость времени, от 1/8 до 64× |
| `R`, `Shift+R` | новый полёт (другой ветер и разброс), тот же полёт заново |
| `1` … `3` | экраны: сводка, эфир (камеру выбирает режиссёр, повторное `2` листает семь бортовых), свободная камера |
| мышь | перетаскивание — поворот, колесо — приближение |
| `V` | переключить ступень |
| `Enter` или `S` | ручное разделение |
| стрелки | тяга и тангаж вручную, `,` и `.` — крен |
| `,` `.` `/` | в разборе полёта: прыжок по вехам назад, вперёд, один шаг физики |
| `0` или `A` | вернуть управление автомату |
| `T` | ДМТ вкл/выкл |
| `B`, `N`, `M` | створка отсека, выпустить 1 аппарат, выпустить 10 |
| `G`, `L` | дым старта, плоский свет |
| `Esc` | выход |

Аргументы командной строки пробрасываются через `play.bat`: `--mission`, `--seed`,
`--nodisp` (без разброса), `--anom`, `--t` (перемотка), `--screen` (1 сводка, 2 эфир, 3 пульт), `--theme` (a, b, c),
`--cam` (камера по номеру: −1 орбитальная, 0–6 бортовые, 7–12 стартовый комплекс), `--eng` (двигатель на пульте), `--cuts` (лист склеек режиссёра),
`--free`, `--shot`, `--camcheck` (проверить, что бортовые камеры стоят на обшивке).

## Файлы

* `game/src/Sim/` — физика: атмосфера, аэродинамика, баки, наведение, такт моделирования.
  **Ни одного вызова Godot** — та же сборка идёт в стенд
* `game/src/Engines/` — модель Raptor и турбонасосных агрегатов
* `game/src/Game/` — сцена, камеры, отрисовка, ввод, снимки, задания
* `game/src/Game/Ui/` — три экрана: сводка, эфир и пульт; задание, графики, журнал
* `game/src/UiLogic/` — интерфейс без Godot: числа, темы, схема двигателей, зоны — идёт в SimTests
* `game/tests/SimCheck/` — стенд сверки: та же физика без движка, сводка из 98 чисел
